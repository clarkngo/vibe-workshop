Judgment & Guardrails

When to trust AI output, when to verify it, and what "verify" means for people who don't read code.

Overview & Objectives

Modules 1 and 2 built the loop and the skill of prompting well. This module is about the last, hardest step: deciding how much to trust what comes back, and what "verify" actually means when you're not the one reading the code.

By the end of this module, you'll be able to:

  • Explain the difference between output that "looks right" and output that's been verified
  • Apply a lightweight verification checklist scaled to how much damage a wrong answer could do
  • Identify who to loop in when AI output touches something high-stakes

Prerequisites: Modules 01–02.

Content Modules

s1 — "Looks right" isn't "is right"

Everyone in the room can eyeball whether an answer looks plausible — that's not a technical skill. Verification is different: it means you did something that would have caught the answer if it were wrong. Reading confidently-written prose is not that something, for anyone, technical or not.

Non-technical readers

You can verify without reading code: run it and check the actual result against what you expected, ask the AI to explain its reasoning and see if the explanation holds up, or hand it to someone who can read it. "I can't read the code" is not the same as "I can't verify the output."

s2 — Scale the checklist to the blast radius

You don't need the same verification effort for every task — you need it proportional to what happens if this specific answer is wrong. Use Module 1's "good fit / needs more rigor" table as a starting point, then apply this:

Blast radiusMinimum verification
Low — just for you, easy to undoSkim it, run it, move on.
Medium — others will see or use thisRun it against a real example; check the edge cases you can think of.
High — money, access, personal data, or it's hard to undoA second person reviews it before it ships. No exceptions.
3

Activity — Name the Blast Radius

Type: Discussion, pairs · Time: 10 min

Each pair picks one real task from their own work — something they'd actually consider vibe coding. Answer out loud: what's the blast radius if the AI gets it wrong, and who would need to be looped in before it ships? Report one example back to the room.
