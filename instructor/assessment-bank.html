Module 04 — capstone rubric

Reproduced from the module page. A capstone is "done" when:

  • Success criteria were written down before building started
  • The loop was visibly run more than once — no first-draft-and-ship
  • Verification effort matched the stated blast radius
  • The builder can explain why, not just that, each decision was made
