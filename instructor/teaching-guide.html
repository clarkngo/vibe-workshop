Pacing risk

Module 04 is the single largest block and the one most likely to run long, since "build" time compresses for anyone whose real task turns out bigger than expected. If you're tight on time, protect the Critique step (4) over extending Build (2) — critique is where the judgment skills from Module 3 actually get exercised.

Per-Module Facilitation Notes

Module 01 — What Is Vibe Coding?

Non-technical participants sometimes assume this module is "not for them." Frame it early: the loop (prompt → generate → read → judge) applies whether or not you can read the generated code — Module 3 makes that explicit, but it's worth a one-line preview here.

Module 02 — The Vibe Coding Loop

This is the densest module. If the room is running behind, the Simulation (s2) is the safest thing to shorten — walk through one prompt level live instead of all three. Do not cut the Activity; "What's Missing?" is what makes s1 stick.

Module 03 — Judgment & Guardrails

Watch for participants picking a trivially low-stakes example for the "Name the Blast Radius" activity to avoid a harder conversation. Gently push at least one pair per room toward a real medium/high-stakes example — that's where the module's actual value shows up.

Module 04 — Capstone

The biggest facilitation risk is scope: participants pick a task too big for 35 minutes of build time. Circulate at the 10-minute mark and flag anyone whose stated success criteria look like a multi-day project, before they've sunk build time into it.

3

Misconceptions to Watch For

  • "Vibe coding means never reading the code." No — Module 2 exists specifically because review effort shifts, it doesn't disappear.
  • "If it runs without an error, it's correct." No — Module 1's hallucination point and Module 3's verification point both push directly against this.
  • "Non-technical people can't verify anything." No — Module 3 s1 gives non-code verification paths explicitly. Call this out if you see it come up.
  • "More iterations always make it better." No — Module 2's scope-creep warning. More iterations without a stated success criteria drift, they don't converge.
