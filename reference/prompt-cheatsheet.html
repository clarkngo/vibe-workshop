Prompt Cheat Sheet

From Module 02, condensed to one page for the walk back to your desk.

1

Four ingredients of a prompt that holds up

Context

What already exists. Paste the current code, not a description of it.

Constraints

Language, library, performance, style — say what's fixed.

Example

A concrete input/output pair beats another paragraph of description.

Success criteria

How you'll know it's done — a test passing, a page loading, an edge case handled.

2

Reading output — three questions

  1. What actually changed? (Check the diff, not the summary.)
  2. Does it match what I asked for?
  3. Any red flags — unrecognized functions, unrelated imports, swallowed errors?
3

Iterating without starting over

PatternWhen to use it
Narrow the askThe shape is right, one part is wrong — name the part, leave the rest.
Paste the error verbatimYou have an exact error message — don't paraphrase it.
Ask for the reasoningOutput looks odd but doesn't obviously fail.
Ask for testsYou're not sure the logic is right.
4

Blast-radius checklist

From Module 03 — scale verification to what happens if this specific answer is wrong.

Blast radiusMinimum verification
LowSkim it, run it, move on.
MediumRun it against a real example; check edge cases.
HighA second person reviews it before it ships. No exceptions.
