# Archive

Parking lot for content that drifts out of scope for this workshop — a different course's pages, a superseded module draft, anything that shouldn't live in the active site but also shouldn't just vanish.

Empty right now. That's expected: per the [archetype blueprint](../../workshop-archetypes/index.html), the source course this pattern is based on had no such folder, which is exactly how an unrelated course and an orphaned workshop outline ended up mixed into its live site with no label. If something drifts, it goes here with a one-line note on why, not silently into the root.
